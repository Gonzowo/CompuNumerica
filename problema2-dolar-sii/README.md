# Proposito de cada codigo python:

# carga_datos.py
Esta encargado de leer el archivo .csv y traducirlo a un diccionario accesible para el resto de codigos

# errores.py
Esta encargado de, en base a un diccionario del precio mensual año a año del dolar, calcular el error absoluto y relativo utilizando la libreria numpy, ademas de almacenar en una variable el mes con mayor error absoluto/relativo del periodo

# evaluacion_entre_puntos.py
Se encarga de, en base a un capital inicial, calcular la rentabilidad de invertir desde un mes en especifico hasta otro mes futuro.

# anualidad.py
Calcula la variacion enero/diciembre de cada año

# puntoflotante.py
Genera un grafico comparando Monto Exacto y la curva que genera en el tiempo, lo almacena en la carpeta graficos, tambien entrega el calculo de 874.67 − 875.66 entre float32 y float64

# mejorcompraventa.py
Entrega los mejores meses para comprar y vender, almacenado valores y entregando el maximo en consola

# variacion_dolar.py
Calcula la variacion del dolar entre los periodos seleccionados (Diciembre 2022-2023 por defecto) y entrega los resultados en consola
